# ☕ Coffee Shop – Sprint 4

Este projeto foi desenvolvido durante a Sprint 4 do curso Web Development da TripleTen. A proposta foi criar uma página web estática para um café fictício, utilizando apenas HTML e CSS. 

A cada etapa, novas seções foram adicionadas: cabeçalho com navegação, seção de receitas com vídeo, formulário de reservas e outras áreas que compõem uma landing page completa. Também foram aplicadas boas práticas de semântica, responsividade e organização de arquivos.

**🎯 Objetivo do Projeto**

Construir uma página web responsiva em HTML e CSS, utilizando estrutura semântica, formulários personalizados, vídeo incorporado, e organização modular de arquivos.

**✅ Resultado**

O projeto foi concluído com sucesso conforme os requisitos técnicos da Sprint 4. A página simula o site de um café real, com conteúdo bem estruturado e visualmente agradável. Um dos maiores aprendizados foi lidar com formulários HTML e incorporar vídeos externos, além de reorganizar a estrutura do projeto conforme ele crescia.

**🛠 Tecnologias Utilizadas**

- HTML5  
- CSS3  
- Flexbox  
- Google Fonts  
- Incorporação de vídeo (YouTube)  
- Metodologia BEM  
- Git e GitHub  

**⚙️ Funcionalidades**

- ✅ Layout com múltiplas seções (header, receitas, reservas, etc.)  
- ✅ Incorporação de vídeo do YouTube na seção de receitas  
- ✅ Formulário de reservas com campos estilizados  
- ✅ Responsividade com Flexbox  
- ✅ Organização de arquivos por seções  
- ✅ Estrutura semântica e classes nomeadas com BEM  

**🚀 O que aprendi com esse projeto**

- Criar estrutura de página mais extensa e com várias seções  
- Trabalhar com formulários HTML e aplicar estilos personalizados  
- Colocar vídeos externos de forma correta  
- Aplicar Flexbox para ajustar layouts em diferentes tamanhos de tela  
- Reorganizar o projeto à medida que cresce  

**🔧 Melhorias Futuras**

- Adicionar validação real ao formulário com JavaScript  
- Implementar efeitos de rolagem suave e transições visuais  
- Otimizar o carregamento das imagens e vídeos
